2. 读懂这五列数据

字段含义与单位本题约定
time相对时间，秒必须严格递增；第一份日志为 0–20 s
x, y平面位置，米同一固定坐标系；每两行代表一个移动区间
yaw朝向，弧度绕平面法向的朝向角；本关不用于计算路程
battery电量百分数，0–10090 表示 90%，不是 0.90；不能当作能量单位 Wh

正常日志模拟沿边长 2.5 m 的正方形走一圈，共 21 个位置点、20 个移动区间。相邻点相隔 0.5 m、1 s，因此累计路程 10 m。

从 CSV 到数字

import csv

with open("data/motion_log.csv", encoding="utf-8-sig", newline="") as f:
    for row in csv.DictReader(f):
        print(float(row["time"]), float(row["x"]), float(row["y"]))

DictReader 让你通过列名取值；CSV 读出来的字段仍是文字，计算前要转为 float。参考程序的 load_log 还检查缺列、空值、无穷值、电量范围和时间顺序。

3. 把问题拆成四个计算

  1. 每段路程：对相邻两点求 dx、dy，再用 math.hypot(dx, dy) 计算直线距离；累计所有段得到总路程。
  2. 平均速率：总路程除以末尾时间与起始时间之差。时间间隔不相等时，不能直接平均各段速率。
  3. 电量下降：起始电量减去结束电量。90% 到 85% 是下降 5 个百分点。模拟数据没有提供电池容量、负载和正常基线，不能据此诊断电池异常。
  4. 可疑分段：每段路程除以该段时间间隔；本题把严格大于阈值的区间记录下来。
import math

for before, after in zip(rows, rows[1:]):
    dx = after["x"] - before["x"]
    dy = after["y"] - before["y"]
    distance = math.hypot(dx, dy)
    dt = after["time"] - before["time"]
    speed = distance / dt

路程与位移不同：绕一圈回到起点，累计路程是 10 m，起终点位移大小是 0 m。这里由采样点连线估算路程，稀疏采样和定位噪声都可能影响真实实验的估计值。

基础补充：zip、列表和字典分别做什么？

rows 是按时间排列的列表；每个元素是一个字典，例如 {"time": 1, "x": 0.5, "y": 0}。rows[1:] 跳过首行，zip(rows, rows[1:]) 就能每次取出相邻两行。用 distances.append(distance) 保存每段结果，再用 sum(distances) 求总和。
