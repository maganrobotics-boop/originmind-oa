# 第 7 关：把学习过程交付给另一个人复现

建议 45–60 分钟。前置：前六关的真实成果与记录。本关不是再上传一堆截图，而是把“目标、改动、结果、解释、文件”对应起来。

## 1. 下载证据整理材料

[下载完整材料包](lesson.zip) · [虚构样例清单](sample/manifest.json) · [个人清单模板](manifest.template.json) · [检查与打包程序](audit_evidence.py) · [提交单](submission.md)

sample 目录仅含教学用虚构说明，字段 is_demo 为 true，不是实际学生完成课程的证据。你自己的成果放在单独的 my-evidence 文件夹中。

## 2. 跟着样例整理一次

在材料目录运行：

```text
python audit_evidence.py sample/manifest.json
python audit_evidence.py sample/manifest.json --pack demo-evidence.zip
```

应看到 `DEMO_ONLY 示例结构通过，不可作为个人作业`，并统计 6 个关卡、6 个样例文件。压缩包包含清单、文件与 SHA256SUMS.txt。哈希用于核对文件是否被改变，不能证明作者身份、真实运行或内容正确。

逐项观察 manifest：id 对应关卡，command 是实际运行命令或登记操作，expected 是事先预测，actual 是实际结果，change 是你做的改动，explanation 是你对结果的解释，files 是能支撑结论的本地文件路径。

## 3. 修改成自己的证据清单

新建 my-evidence，把 manifest.template.json 复制进去并重命名为 manifest.json，按关卡建立文件夹，把自己实际完成的代码、日志、结果与说明复制进去。

把 is_demo 设置为 false；逐项填写前六关的真实状态与证据。files 使用相对路径，例如 `python/exercise.py` 和 `python/result.txt`。每关至少一个非空证据文件，实际验收仍以该关的提交要求为准。

模板中的 status 默认为 in_progress。只有真正达到该关验收标准时才改为 completed。ROS2 只有离线预检时，应保留进行中并写出阻塞原因；程序会拒绝生成“已齐全”的提交包。不要用改状态来掩盖未完成工作。

填写反思 reflection、下一步 next_goal、助教/AI 帮助 ai_help；未使用可写“未使用”。保留个人思考和真实排错记录，使用参考代码也应说明。

```text
python audit_evidence.py my-evidence/manifest.json
python audit_evidence.py my-evidence/manifest.json --pack my-evidence-v1.zip
```

打包不会覆盖同名文件；修改后用新版本名，例如 v2。超 25 MB 的单个视频可保存到获准的共享位置，再把链接、访问权限和说明写进证据文本。不要把令牌、密码、私人信息或未经授权的项目资料装入包。

变化任务：暂时把一个证据文件改名，运行检查，确认它准确报告缺失；恢复文件名后再检查。保存这次失败与修复的记录，证明你理解清单与文件的对应关系。

## 4. 对照验收标准

| 维度 | 通过标准 |
| --- | --- |
| 完整性 | 前六关各有状态、命令/操作、预期、实际、改动、解释和证据 |
| 可复现性 | 他人能用 README 中的环境和命令找到并复现关键结果 |
| 正确性 | 结果符合各关标准，真实仿真与理论样例明确区分 |
| 可解释性 | 能解释至少一次失败、定位依据和修复后的变化 |
| 可追溯性 | 证据路径可打开，代码版本和助教帮助有记录 |

结构检查只做字段、路径和文件存在性检查；它不会自动批改报告，不会确认文件内容是本人完成，也不会自动授予真机或项目权限。

## 5. 提交证据与下一阶段计划

填写 submission.md，附证据包、检查结果、一页反思和下一阶段计划。做一次 3 分钟演示：30 秒介绍目标，90 秒展示一项修改前后结果，60 秒解释一次失败和下一步。

返回第 7 关，把证据包的授权访问链接与内容摘要填入证据栏。免登录模式仅记录在当前浏览器；正式提交需登录。下载打包程序不会自动上传文件，保存本机进度也不等于教师验收通过。

## 常见问题与助教提示

- 文件缺失：manifest 中的路径相对于 manifest 所在目录，不是电脑桌面或程序所在目录。
- 结构通过但导师打不开链接：检查共享权限与有效期，先用未登录窗口确认授权的阅读方式，不公开不应公开的资料。
- 还有一关没完成：先记录阻塞和下一步，不要把示例充当成果；可继续整理其他关证据。
- 问助教：“请依据这个清单指出缺失证据，不要把未完成关卡改为通过，也不要替我编造实验结果。”
