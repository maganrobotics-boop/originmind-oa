# OA 顶部管理员设置入口

工作台最上方“待我处理”的紧右侧只保留一个“管理员设置”按钮，点击进入 `/admin`。模型、实时字幕、会议与系统管理从该管理页进入。此前内容区右侧的四个卡片已移除。

入口仅对 OA 系统管理员显示。现有管理员认证和权限检查继续生效。

顶部管理员布局为明确的同一行网格：“待我处理”位于第 3 列，“管理员设置”位于第 4 列，账户菜单位于第 5 列。窄屏缩小间距，并将账户入口显示为头像，减少挤占空间。

## 生产源码说明

当前 GitHub 主分支与阿里云线上源码存在差异。这里保存独立组件和针对真实生产基线的增量补丁，避免用旧主分支覆盖当前 OA 功能。

- 生产基线：`/opt/omindos-deploy/releases/oa-subtitle-admin-20261014-v1`，文件哈希见 `manifest.json`。
- 发布版本：`/opt/omindos-deploy/releases/oa-admin-settings-topbar-20261014-v3`。
- 应用前核对基线文件哈希，复制本 PR 的两个组件文件，然后对生产基线执行 `git apply --check deploy/oa-workbench-settings/production.patch`，检查通过后应用补丁。
- 补丁包含顶部入口接入，以及已有管理页分区锚点；无需数据库迁移。

## 验证

生产构建及完整 TypeScript 检查通过。React 渲染检查确认管理员只有一个 `/admin` 入口，普通成员没有该入口。源码确认新按钮紧接顶部待办按钮，旧四卡片组件已移除。服务身份预检通过，并保留旧版本静态资源以支持已打开的页面。
