# 荣誉墙与个人奖杯 V1

用户要求：崔航阁、刘奕鹏、邱衡为首批新手村通关荣誉；个人主页展示奖杯，所有人可查看公开荣誉墙；管理员可补录历届毕业生、竞赛获奖和项目贡献，授予、隐藏及撤回均有记录。荣誉独立于课程解锁、成绩、XP、通行证和卡关救援。

## 使用入口

- 公共页：`/learning/honors`，匿名可查看，按类别筛选、按授予时间分页展示。
- 个人页：`/newbie-village#profile` 的“我的荣誉”。需现有 visitor 登录态，账户由服务端会话确定，不支持按邮箱查询他人奖杯。
- 管理页：`/learning/honors/admin`，复用当前 Chat 管理员会话与登录。原 `/newbie-village/admin` 中也有入口。

管理页填写姓名、类别、名称、可公开事迹、确认方式及内部确认依据，并人工勾选确认后授予。未知的事迹日期可以留空，历史日期与系统实际授予时间分别记录。旧生没有系统账号也能先记入荣誉墙；后续核验准确账号后手动绑定。

账户查询只返回候选邮箱、个人姓名、最近签署姓名和时间，不自动认领或按同名绑定。管理员必须选择账户并保存核验说明。更正账户绑定同样记录新邮箱和理由。账户候选与来源材料只有管理员可看。

- **隐藏**：从公共荣誉墙移除，获奖人仍能在登录后的个人主页查看，标记“仅本人可见”。
- **恢复公开**：恢复公开展示，不改变授予日期或事实。
- **撤回**：个人和公共页均不再展示；保留原事实、来源和历次操作。已撤回记录不能通过恢复公开重新授予，如需更正后再授予，新增经确认的记录。

## 数据与权限

迁移 `chat-cloudflare/migrations/0008_learning_honors.sql` 新增两张表：

| 表 | 用途 |
| --- | --- |
| `learning_honors` | 一条荣誉一行：公开姓名、可选私有账户邮箱、类别、名称、公开事迹、可选事迹日期、内部确认方式与依据、授予人/时间、可见范围、状态、版本、更新时间。 |
| `learning_honor_events` | 私有操作记录：荣誉 ID、版本、动作、操作者、时间和说明。一条记录对应一次导入、授予、绑定、隐藏、恢复或撤回。 |

公开 API 使用固定字段白名单，不返回账号、来源内容、操作者标识或操作记录。接口和页面不缓存荣誉响应。个人请求拒绝邮箱等身份选择参数，撤回记录不会返回；同名昵称不能获得奖杯。

管理员鉴权复用 `requireOwner`，教师/学生 visitor 会话不等于管理会话。写入必须同源、有明确确认和非空来源，采用有限请求频率；撤回与绑定等操作需说明。版本条件与原子批处理防止旧页面覆盖新记录，并保证变更与操作记录同时成功或同时失败。授予使用客户端请求 ID，丢失响应后重试不会重复授予。类别固定为 `newbie` / `alumni` / `competition` / `contribution` / `other`，暂不增加排行榜或自动推断规则。

## 上线接续

本变更基于仓库 main `2428f2f6038aba826a70f8f9ba9b7fde3512ec6c`。当前阿里云 `/learning` 比仓库新，不能用此 main 的整套页面直接覆盖线上课程或整站源码。此变更没有操作生产数据库、合并 main 或切换线上服务。

4. 较新的 `/learning` 主页面需要接入以下窄接口，在个人资料区域放置 `.personal-honors` 容器，并加载 `/learning/honors.css` 和 `/learning/honors.mjs`。每次服务端确认登录身份、切换账户或退出后更新容器的 `data-account`，退出/游客设置为空字符串；然后派发 `honors-account-change`。邮箱仅作为前端丢弃旧请求的标识，私有 API 仍从服务端会话取身份。仓库 `/newbie-village` 已接入此接口。
