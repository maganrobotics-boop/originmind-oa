# OA 百炼任务执行工具增量（2026-09-18）

## 本次实现

在 PR #84 的 OA 私有任务链路中，把单次正文生成替换为真实的百炼 Function Calling 循环：发送服务器固定工具定义 → 接收 tool_calls → 严格验证参数 → 执行工具 → 把真实工具结果传回百炼 → 构建文档。模型只说“已完成”不会产生成功任务。

本增量没有新增飞书入口，没有修改公共 Chat、真人聊天、OA 页面、成员准入或审批规则。与同分支新增的私有成果归档保持兼容，不覆盖那些修改。

| 工具 | 实际操作 | 边界 |
| --- | --- | --- |
| read_material | 按行读取本次提交的文字，返回行数及截断提示 | 不读取其他成员记录、磁盘路径或网页 |
| search_material | 对本次材料作字面查找，返回行号和片段 | 不是全 OA 知识库检索，也不是互联网搜索 |
| table_statistics | 解析材料中的 CSV/TSV，程序计算数量、合计、均值、最小值、最大值 | 第一行表头；只使用原始材料中的数值，不接受模型自编数据 |
| prepare_document | 实际构建 Word 字节，并计算 Word/Markdown 的 SHA-256 | 终结工具；只准备文件，不能自行宣称已归档或已发送 |

表格内容可直接粘贴到材料框；本次没有扩展文件选择器，仍只支持已有的 TXT/Markdown 上传。不是 Excel 工作簿解析。表格上限 1000 数据行、64 列、总材料 20000 字；统计列只接受至多 12 位整数和 6 位小数，不接受货币符号、百分比、公式、科学计数法或空值。空行、无效数据不会被当成零或静默跳过。合计/极值使用定点整数运算；均值明确四舍五入至 6 位小数（中点向远离零方向）。

## 执行与权限

服务器白名单固定，模型不能增加工具、选择另一个用户、执行 SQL、运行脚本、访问 URL、发送消息、审批、删除或公开资料。材料中的指令不授予能力。

每次任务最多 6 轮模型调用、12 次工具调用，总执行窗口 60 秒；每轮上游请求分别占用现有全局模型预算。无自动网络重试，不跟随重定向，百炼任务失败不偷偷切换到其他供应商。

私有服务接口仍要求 HMAC、时间戳、一次性请求编号，并拒绝浏览器 Cookie/Origin。API 密钥只用于上游授权头，不进入材料、工具结果或执行记录。

工具返回的 execution.state=prepared 不等于 OA 归档成功。现有 runTask 仍负责成员/NDA/版本/取消/租约复核，以及文件制作校验和事务保存。execution 中的步骤信息目前仅返回给私有服务客户端，没有新增步骤日志表、实时进度展示或持久化执行审计。已经发送给模型的请求在取消后不保证立即中止；最终结果不得绕过保存阶段的取消与权限检查。

## 本次验证

使用 Node.js v22.16.0，在更新后的核心校验模块上执行：

```sh
node --test tests/ai-workbench-tools.test.mjs tests/ai-workbench-bridge.test.mjs
```

结果：66 项通过，0 失败，0 跳过。其中 60 项为工具/传输专项测试，6 项为私有桥接测试。覆盖真实工具执行、精确统计、文件字节/哈希、HMAC/密钥解密、参数越权、重复调用、预算、超时、重定向、截断响应和伪造完成状态。

所有模型决定、API 密钥、上游 HTTP 回应均为明确合成测试数据；工具代码和文档构建不是模拟。没有真实百炼调用、付费调用或消息发送。该测试结果不等于完整 npm 构建、全套回归、浏览器联调、Cloudflare 部署验证或生产验收。

开发较早阶段曾在旧核心模块上完成 69 项测试；随后同分支删除飞书任务并更新成果归档，因此本次最终工具增量的可复现验证口径以上述 66 项为准，不叠加或混算。

## 上线边界与后续验收

本次不合并、不部署、不执行生产数据库迁移、不设置 Secrets、不启用 OA_AI_TASKS_ENABLED。PR #84 的整体工作台仍需按其发布文档核验 0002/0003 迁移、私有服务绑定及现有百炼配置。当前配置的实际模型还必须通过一次真实 Function Calling 联调，不能仅凭普通聊天可用推定工具调用已验收。

本增量没有新增迁移文件。未实现 PDF/PPT/XLSX、图片理解、网页读取、跨 OA 知识库取数、发消息、审批和任意脚本执行。先完成完整构建及回归，再经生产授权启用。
