# OA AI 工作台：一次性启用与验收

## 已发布与尚待完成

OA 代码 ba2d8a7 已由正式发布 run 35325040299 上线；复用的 Chat / 百炼后台由 run 35326065813 上线，release 和发布后浏览器检查均成功。上述普通发布没有初始化 OA 私有任务表，也没有启用 OA_AI_TASKS_ENABLED。

本补丁把缺失的一次性启用步骤接入已有 `.github/workflows/deploy-oa.yml`，不新增绕过保护的发布通道。合并补丁本身不会开启生产工作台。

## 手动发布入口

在原 OA 发布工作流选择 main，填写既有生产环境的精确 Worker:D1-UUID:hostname confirmation，然后勾选 `enable_ai_workbench`（中文说明：初始化并启用 OA AI 工作台）。

该选项默认 false：不勾选时保持原生产变量，不执行工作台 SQL 或真实模型自检；它不是关闭已有工作台的开关。

勾选后按顺序执行：

1. 保留完整安装、类型检查、lint、构建与测试，以及 protected environment、main、手动事件、精确目标和发布互斥检查。
2. 复制并校验已审阅的 0002/0003 SQL 字节，纳入不可变发布文件清单；读取任务表结构，不读取成员记录。已有结构不兼容时停止，不擅自改表。
3. 用固定合成材料调用已发布的百炼任务桥接，验证真实工具调用和可制作的 Word / Markdown；这一项任务最多使用现有工具循环允许的模型轮数，消耗既有模型预算，不修改预算或付费设置。失败时停止，不切换其他模型供应商，不写入任务表，不启用新功能。
4. 在数据库操作前记录并校验 D1 Time Travel 恢复书签。它是供应商恢复点，不是另存的完整 SQL 备份；不会把旧自定义 OA 导出包当作包含任务文件的完整备份。
5. 只对精确核验的 OA DB 执行已审阅的两份 CREATE IF NOT EXISTS 扩展 SQL；不改变 Drizzle 历史迁移账本、不操作 WEBSITE_DB、不删除旧表或资料。执行后核对全部任务表及索引结构。
6. 在同一次严格部署中加入固定的非秘密变量 OA_AI_TASKS_ENABLED=true，其他远端变量继续保留。部署参数、SQL 哈希及验证回执留存，不接受任意额外变量或目标。

## 验收范围

真实模型自检只使用合成文字，验证百炼提供商、读取材料类工具、prepare_document、两种文件的制作和完整性；回执不包含原文、模型正文或凭据。

这个自检不伪造成员登录，不写入真实成员的任务记录，因此不能代替以下最终验收：已准入成员登录 OA → 提交合成任务 → 成功后刷新 → 下载 Word / Markdown → 打开文件检查，并确认其他成员不可访问。发布后的公共只读 smoke 同样不能代替这一步。

本补丁不新增飞书 AI 入口、不修改原登录与审批业务、不调整模型额度、不自动审批或公开成果。

## 失败和回滚

初始化或自检失败时发布失败，查看所在阶段，不盲目重复付费模型自检。新增表为可重复运行的加法迁移，不执行 DROP TABLE。若部署已完成但最终 smoke 失败，不自动恢复数据库；保留恢复书签和 Worker 版本供人工核对。

需要停用时由有权限的管理员把远端 OA_AI_TASKS_ENABLED 设为 false；必须复核停止状态，不能把一次普通未勾选发布当作停用。已有私有任务文件不得因回滚而删除。
