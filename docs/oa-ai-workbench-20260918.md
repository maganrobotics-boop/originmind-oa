# OA AI 工作台：实际文件交付（仅 OA，默认关闭）

## 产品范围

实验室成员在 OA 的 AI 助手页面进入 `/ai-workbench`，输入任务要求并粘贴材料，
或选择 UTF-8 TXT / Markdown 文件。第一版交付文档整理、项目周报、会议纪要、项目方案。
任务要求是主要输入，标题可留空，按任务要求自动命名；提供四种常用任务模板。

真正执行的流程为：

`接收材料 → 百炼生成正文 → Word / Markdown 文件制作 → 字节校验 → 私有归档 → 下载`

模型只生成正文，不负责宣布任务成功。服务器制作真实 OOXML Word 文件及 Markdown 文件，
计算字节数与 SHA-256，再将两份文件和成功状态在同一个 D1 batch 事务中保存。
下载读取归档字节并校验哈希，不再临时生成文件。任一文件制作或保存失败，不显示成功。
材料、任务、正文和文件仅本人可见，刷新后仍可重新读取。
文件完整性检查不等于事实核验，成员仍需核对生成文档中的具体事实。

第一版只处理文字，最多 20,000 字材料、2,000 字要求。Word 保留标题、正文、加粗及简单表格。
不读取图片、PDF、Word 输入附件或网址正文，不生成 PPT / PDF / Excel，不运行任意脚本。
没有加入自动公开、代发消息、审批通过、删除正式资料等动作。

## 仅 OA，不依赖飞书任务配置

已移除本次新增的飞书 AI 消息回调、机器人任务接收/发送、消息加密模块及页面说明。
队列、读取、重试、执行与文件访问只处理 `origin='oa'`。
AI 工作台不需要飞书机器人、消息订阅、账号绑定或新的飞书 Secrets。
现有 OA 飞书登录、普通审批通知和 PDF 归档不是本次删除范围，保持原逻辑。

继续复用既有 OA → Chat 的签名私有服务桥接和已配置的百炼供应商；
这是后台服务复用，不经过公共聊天接口，也不写入公共知识库或聊天历史。
任务遇到百炼失败时不自动切换其他供应商。

## 状态、权限和重试

- `queued / running / succeeded / failed / cancelled` 均来自数据库实际状态。
- 执行前与归档前检查实名成员、稳定账号、成员版本、有效的已归档保密协议；下载再次核验。
- 幂等创建、原子执行租约、每人每日最多 100 项、同时最多 5 项；重试也不能绕过并发限制。
- 每项最多执行 3 次；超时任务标记失败，不自动重复付费生成。
- 取消、成员准入变化或租约到期后返回的迟到结果不得保存。
- 归档表尚未迁移时，执行在调用模型前停止。
- 文件制作、存储失败有独立错误状态，不将上游异常内容或私有材料打印到日志。

未启用的旧飞书结构不再使用，也不擅自删除可能已有的数据。

旧版只有正文、没有归档文件的记录不会伪装成可下载成果；应由本人新建任务生成文件。
关闭 `OA_AI_TASKS_ENABLED` 可停止任务接口与队列；部署回退不执行 DROP TABLE。
任务扩展表未纳入原自定义 OA 导出器，备份/迁移必须额外保留这些表；
在补齐导出器前，应使用并核验目标 OA D1 的完整原生备份，不将旧导出包当作完整任务备份。
