# OA：在同一聊天窗口导入材料并交付文档

## 交付范围

移除聊天顶部独立 AI 工作台链接；欢迎语改为“需要实验室大模型做什么？”。底部提示资料整理/Word、会议纪要、周报方案和知识问答四类能力。聊天框的加号读取 UTF-8 TXT、MD / Markdown；原文立即显示在当前对话，长文可完整展开。选择文件本身不调用模型，不写入共享知识库。

发送处理要求后复用 `/api/lab-ai/tasks` 的创建、执行、校验、归档及本人下载接口，显示同一对话中的状态与文档卡片；成功后自动打开原生对话框预览，支持 Word / Markdown 下载、继续修改和返回聊天。“已保存文档”通过已鉴权接口恢复本人的最近 30 项任务，不需要跳去工作台。原工作台路由保留用于旧书签兼容。

## 安全和故障边界

- 不修改任务 API、成员准入、保密协议检查、任务归属、数据库、Secrets 或模型计费。
- 原文作为文字显示；成果复用现有 DOM-safe renderer，不执行导入材料中的 HTML。
- 一份输入最多 90 KB、20,000 字，任务要求最多 2,000 字，均与现有服务约束一致，超限报错，不截断原文。
- 没有原始资料的写作请求明确标注缺少事实，不以空输入伪造资料读取成功。
- 创建结果不确定时人工“核对提交”沿用同一 requestId；失败可手动重试；轮询只读，绝不自动重复调用模型。
- 取消与成功不被迟到的 run / poll 响应覆盖；清空聊天或卸载会中止本页等待，迟到结果不重新插入对话。清空聊天不删除服务器保存的成果。
- 服务没有启用或模型失败时明确显示错误，不交付假附件；普通知识问答仍走原接口。
- 文档不写 localStorage；预览和下载仍受现有 OA 会话与服务器权限控制。

## 验证

新增 18 项 Node 测试，覆盖意图路由、UTF-8、文件类型/大小/字数、原文保留、任务计划和迟到状态防护。新增真实 OA 页面 Playwright 场景，使用完全合成 API，覆盖桌面/手机/横屏、问答与任务分流、上传原文、预览与真实 DOCX 生成下载、继续修改、手动重试、创建去重、取消后迟到回包、刷新恢复和服务错误。

本改动不自动合并、发布、启用任务开关或重新部署公共 Chat。线上可用性仍须以现有生产发布及一次真实百炼任务验收为准。
